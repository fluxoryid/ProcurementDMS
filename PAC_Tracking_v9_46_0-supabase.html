💾 Backup Database

Saves a full disaster-recovery snapshot as a single file, named BackupDB-yymmdd-hhmmss-ms-#####.dat — every record in every tab, Chat (threads & messages), Approval Requests, and the actual bytes of every uploaded document (not just their file names), so a restore reproduces the live application state exactly. Supabase Auth accounts (passwords) are the one thing that can never be included — they're one-way hashed by Supabase itself and cannot be extracted or restored by any application; re-create user accounts separately if needed. Building the backup downloads every file from Storage, so it can take a while with many documents. Browsers can't write to an arbitrary folder path automatically for security reasons — when the picker opens below, navigate to Procurement Shared Folder\Narti\Document Tracking Storage\Backup Database\ and select it (Chrome/Edge only). Every backup after that writes straight there with no repeated prompts. Without a connected folder, Create Backup Now falls back to a normal browser download instead. Connect it in Setting (under Administration).
